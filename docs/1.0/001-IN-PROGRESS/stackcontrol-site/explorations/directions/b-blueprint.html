// deskwork · lifecycle plugin · v1

Lifecycle tooling for agentic development.

stackcontrol.org is the home of deskwork — the /dw-lifecycle:* and /deskwork:* toolchain for Claude Code. It moves a feature from definition to ship through a legible pipeline — and chronicles building it in the open. Product page and devlog, one surface.

02 / the pipeline

Five phases. One loop. Every stage is a command.

deskwork models the work as a directed graph. Each node is a real slash command; Audit feeds back into Implement until the diff is clean.

01 · DEFINE

Define

An interview captures the problem, scope, and approach — then writes feature-definition.md.

→
02 · PLAN

Workplan

Phases become a workplan with acceptance criteria, then a parent and per-phase GitHub issues.

→
03 · BUILD ↻

Implement

Tasks are delegated to subagents; commits land at task boundaries — never in one blob.

→
04 · AUDIT ↻

Audit

Cross-model audit barrages review every task. Findings loop back to Implement before Ship.

→
05 · SHIP

Ship

Verify acceptance criteria, open the PR, stop at creation — the operator owns the merge.

03 / orientation
what

A control plane

A plugin toolchain that watches a feature move through definition, planning, build, audit, and ship — with state you can read in the terminal.

why

Agents drift

Agentic builds wander without scaffolding. deskwork pins scope, forces commit boundaries, and runs adversarial review so the diff stays honest.

how

Composable commands

Small, UNIX-style slash commands — one per action. Scope discovery, audit barrages, and an editorial pipeline compose into the lifecycle.
